> [!IMPORTANT]
> In Unity 6.5 and later, Cinemachine 2 is deprecated. To upgrade your project from Cinemachine 2 to a later version, refer to [Upgrade a Project from Cinemachine 2.x](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineUpgradeFrom2.html).

> [!IMPORTANT]
> In Unity 6.6 and later, Cinemachine is a [core package](https://docs.unity3d.com/Manual/pack-core.html) that's distributed with your Unity Editor, so Cinemachine 2 and Cinemachine 3 aren't available in the Package Manager. In the Package Manager, use the Cinemachine version that matches your Unity Editor version instead.
